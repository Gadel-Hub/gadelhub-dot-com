# Homepage fonts

All fonts are self-hosted. Font binaries are unmodified.

- **Upheaval TT (BRK), version 2.09**, by Brian Kent / Ænigma Fonts.
  Download: https://www.1001fonts.com/download/upheaval-tt-brk.zip
  Listing: https://www.1001fonts.com/upheaval-tt-brk-font.html
  The bundled author readme permits freeware use and redistribution with that
  readme intact. Selling or altering the font requires permission.
  `upheaval-readme.txt` is copied byte-for-byte from the archive.
  Used only for the decorative hero headline; no font modification or subsetting.
- **Archivo Black**, by Omnibus-Type.
  Source: https://github.com/google/fonts/tree/main/ofl/archivoblack
  SIL Open Font License 1.1: `archivo-black-OFL.txt`.
  Retains the approved prototype navigation typography.
- **Source Code Pro Regular/Bold**, by Adobe.
  Source: https://github.com/adobe-fonts/source-code-pro
  SIL Open Font License 1.1: `source-code-pro-OFL.txt`.
