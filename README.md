# GADEL Hub website

Static bilingual homepage for the GTÜ Game Development & Electronics Community.

Open `tr/index.html` or `en/index.html` in a browser. The root `index.html` points to Turkish and offers an English link. No build step or package installation is needed.

Shared styles live in `styles.css`. The two locale pages contain semantic HTML so content remains available without JavaScript. Edit both pages when changing visible copy. The hero SVG is an illustration; featured content and event notices are explicitly placeholders until verified community material is supplied. The website uses a cropped derivative of the original logo in `assets/logo/`; the original JPEG remains unchanged.
